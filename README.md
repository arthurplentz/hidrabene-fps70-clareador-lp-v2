# Protetor Solar Facial FPS 70 Clareador — Landing Page (v2 · hero PDP)

Variante da landing page (mobile-first, responsiva) do **Protetor Solar Facial FPS 70 Clareador** da Hidrabene Derma.

Diferença para a v1 (`lp-fps70`): o **hero é uma primeira dobra PDP estilo Body Splash** — carrossel de fotos (1º slide = antes/depois) + buy box com seletor de kits (1/2/3 un) embutido. A seção de oferta com os kits segue no fim da página (oferta dupla).

> ⚠️ **Conteúdo confidencial.** Página não indexada em buscadores (`noindex`). Compartilhe o link apenas internamente.

## Ver online
Hospedado via GitHub Pages — link na seção **Deployments / Pages** do repositório.

## Rodar local
Arquivo estático: basta abrir `index.html` no navegador.

## Estrutura
- `index.html` — página completa (HTML + CSS + JS inline)
- `assets/` — imagens, vídeos (`video/`), logo e selos da marca (`brand/`)

## Checkout
Links Yampi por kit já configurados em `CHECKOUT_URLS` (1/2/3 unidades). O buy box do hero e os cards da oferta de baixo usam os mesmos links.
